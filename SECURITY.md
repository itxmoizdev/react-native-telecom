# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email: **[security@itxmoizdev.com](mailto:security@itxmoizdev.com)**

Include:

- Description of the issue
- Steps to reproduce (PoC if possible)
- Affected package version / platform (Android API level, OEM)

We aim to acknowledge reports within a few business days.

For general package questions (not security), use [opensource@itxmoizdev.com](mailto:opensource@itxmoizdev.com) or GitHub Issues.
